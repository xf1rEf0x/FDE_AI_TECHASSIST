# Level 1 : Build an AI IT Support Assistant

## Client Requirement
Employees frequently ask common IT support questions. The company wants a conversational AI assistant capable of answering these questions. At this stage, there is no system integration. The assistant behaves like a capable LLM-powered chatbot.

## Technical Focus
- LLM Integration
- Prompt Engineering
- Chat Interface
- Conversation Memory
- System Prompts
- Message History
- Basic LangChain Components

## Learners Build
- Chat UI
- Conversation History
- IT Support Assistant Persona
- Prompt Templates
- Basic Guardrails
- Session Memory

## Stretch Challenge

Different users should receive different responses depending on whether they are:
- Employee
- IT Support Engineer
- System Administrator
